# Отчет по лабораторной работе №5
В ходе выполнения лабораторной работы параллельная версия программы на MPI была запущена на суперкомпьютере «Сергей Королёв» с разным количеством процессов: 1, 2, 4, 8.

Исходный код был загружен на суперкомпьютер «Сергей Королёв» и скомпилирован командой:

`mpicxx -std=c++11 -o mpi matrix_mpi.cpp`

Скрипт для запуска находится в файле `start.pbs`. Результаты представлены в директории `results`, а также визуализированы на графике зависисмости времени выполнения от размера графика:

# Вывод
В ходе работы была подтверждена работоспособность MPI-программы на суперкомпьютере «Сергей Королёв». MPI-реализация умножения матриц показывает хорошие результаты для больших задач. Чем больше размер матрицы, тем эффективнее работают несколько процессов.
