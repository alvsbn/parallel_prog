# Отчет по лабораторной работе №4

В ходе выполнения работы была модифицирована программа из л/р Nº1 для параллельной работы по технологии CUDA.

Была проведена серия экспериментов с разными размерами матриц (200х200, 400х400, 800х800, 1200х1200, 1600х1600 и 2000х2000) и различными конфигурациями сетки блоков.
Результаты представлены в файле `results_cuda`, а также визуализированы на графике зависисмости времени выполнения от размера графика:

![](график.png)

## Вывод
Проведённые эксперименты показали, что выбор конфигурации сетки блоков существенно влияет на производительность GPU. Наибольшая эффективность достигается при оптимальном размере блока, так как это позволяет максимально загрузить вычислительные ресурсы GPU.
